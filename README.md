# Jie Chu's personal website

Jekyll site published by GitHub Pages from the `main` branch.

- `/`: academic homepage; edit `index.html` for biography, publications, and projects.
- `/blog/`: paginated blog archive; articles remain in `_posts/` with their existing URLs.
- `_config.yml`: contact details and site settings.
- `assets/css/home.css`: homepage styling, independent of the original blog theme.

`jekyll-sitemap` generates the sitemap automatically. To add a publication, copy an
existing entry in `index.html`, update its authors and links, and update the footer date.
